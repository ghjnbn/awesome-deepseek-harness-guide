# 00 · 什么是 DeepSeek Harness

> 本文基于 dsh 0.1.x 编写，如有出入请提 Issue。

## 一句话解释

**DeepSeek Harness（命令行命令叫 `dsh`）是 DeepSeek 官方开源的 AI Agent 运行时。**

用更直白的话说：

- 你平时用 DeepSeek 聊天，是**你说一句、它回一句**。
- 而 `dsh` 让 AI 变成**能自己动手干活的"智能体"（Agent）**：它能读文件、写文件、执行命令、上网查资料，然后把这些动作连起来完成一件完整的事。

## 它能干什么？

举几个例子，感受一下差别：

| 你只让 AI 聊天 | 你让 `dsh` 这个 Agent 干活 |
|---|---|
| "帮我写个 Python 脚本" | "把 `data.csv` 里的数据清洗一遍，输出成报告" —— 它会自己读文件、写代码、运行、改错，直到完成 |
| "告诉我这个项目怎么构建" | "看看这个仓库，找出所有 TODO，整理成清单" |
| "解释这段报错" | "这个命令报错了，帮我定位原因并修好" |

核心能力：**模型 + 工具（读写文件、执行命令）+ 联网**，三者组合成一个能自主行动的 Agent。

## 它和 Claude Code / Codex 有什么区别？

它们属于同一类东西——**AI Agent 命令行/运行时**。区别在于：

- **Claude Code**：Anthropic 官方，绑定 Claude 模型。
- **OpenAI Codex**：OpenAI 官方，绑定 GPT 模型。
- **DeepSeek Harness（`dsh`）**：DeepSeek 官方，默认接 DeepSeek 模型，但通过适配器也能接其他兼容 OpenAI 接口的服务。

`dsh` 的一个显著特点是**基于 Cordis 插件框架**：模型、工具、会话、甚至 Web 界面本身，都是"插件"。这意味着它很灵活，社区能给它加各种能力。

## 两种官方运行方式

`dsh` 不是"打开一个对话框聊天"，而是一个 **profile 启动器**。官方自带两种 profile：

| Profile | 是什么 | 适合谁 |
|---|---|---|
| `web` | 启动一个浏览器界面（默认 `http://127.0.0.1:3080`） | 喜欢图形界面、想点点点的新手 |
| `headless` | 跑一个任务 → 输出结果 → 退出，全程命令行 | 自动化、写脚本、CI 流水线 |

> 想要"像 Claude Code 那样在终端里交互式聊天"？那是社区插件提供的（如 `@brianynwu/dsh-tui` 等），官方 `dsh` 本身不默认带。本指南先聚焦官方的 `web` 和 `headless`。

## 你需要准备什么

1. 一台电脑，装有 **Node.js 22.19+ 或 24**（下一节会讲怎么装）。
2. 一个 **DeepSeek API Key**（开放平台申请，下一节会讲）。
3. 会复制粘贴命令，就足够了。
